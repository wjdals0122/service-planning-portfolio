## 🚀 GitHub Pages 배포 방법

### 방법 1 — GitHub.com에서 직접 업로드
1. GitHub에서 새 repository 생성 (예: `portfolio`)
2. 이 폴더의 모든 파일을 업로드
3. Settings → Pages → Source: `main` branch, `/ (root)` 선택
4. 저장 후 `https://[아이디].github.io/portfolio` 접속

### 방법 2 — Git CLI 사용
```bash
git init
git add .
git commit -m "Add portfolio"
git remote add origin https://github.com/[아이디]/portfolio.git
git push -u origin main
```
이후 GitHub Settings > Pages에서 배포 활성화.
